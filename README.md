# 🤖 [AI Agents Bootcamp](https://gathin.com/events/ai-agents-bootcamp-650)

**AI Agents Bootcamp** eğitimine hoş geldin! 🚀

Yapay zekâyı sadece kullanmak değil, onunla çalışan sistemler geliştirmek isteyenler için **Türkiye Veri Topluluğu** ile birlikte hazırladığımız bu bootcamp'te, LLM temellerinden başlayarak AI Agent mimarileri, tool kullanımı, RAG ve multi-agent sistemlere uzanan bir öğrenme sürecine birlikte adım atacağız.

6 hafta boyunca teorik bilgileri uygulamalarla destekleyecek, öğrendiklerini gerçek projeler üzerinde deneyerek kendi AI agent sistemlerini geliştireceksin.

## 🤔 Neden Bu Eğitim Var?

LLM'lerin ötesine geçerek, bu modelleri araçlar ve bilgi kaynaklarıyla bir araya getiren **AI Agent sistemlerini** öğrenmeni ve kendi agent'larını geliştirebilmeni hedefliyoruz.

## 🎓 Kimler Katılmalı?

Bu bootcamp, AI Agents alanına ilgi duyan ve kendini bu alanda geliştirmek isteyen herkes için tasarlandı!

## 📚 İçerik

* LLM Temelleri
* AI Agent Mimarileri
* Tool & Function Calling
* Prompt Engineering
* RAG
* Multi-Agent Systems
* Uygulamalı Proje

Ders slaytları, teknik mimari diyagramları ve görsel materyallere [presentation/](presentation/) dizini üzerinden erişebilirsiniz.
